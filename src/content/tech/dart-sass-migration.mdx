## 배경

오래된 Node Sass와 이전 문법에 의존하던 SCSS 환경을 이후 업데이트가 가능한 상태로 바꾸기 위해 Dart Sass 전환을 진행했습니다. 대상은 약 2,384개 파일이었습니다.

## 진행 방식

반복되는 문법 변환에는 AI 보조 도구를 사용했습니다. 변환 결과를 그대로 반영하지 않고 폴더별로 작업 범위를 나눴으며, 전환 전후의 CSS 산출물과 빌드 결과를 직접 확인했습니다.

AI가 주석이나 서식처럼 요청하지 않은 부분까지 바꾼 경우에는 변환 규칙을 수정하고 해당 파일을 다시 확인했습니다.

## 결과

- 약 2,384개 SCSS 파일의 Dart Sass 문법 전환
- CSS 산출물과 빌드 결과를 기준으로 예외 파일 검증
- 이후 Sass 업데이트를 이어갈 수 있는 기반 마련

전환 자체로 빌드가 빨라지지는 않았습니다. 별도의 빌드 개선 작업에서 직렬 실행을 병렬화했고, 대표 실행 시간이 약 24초에서 14초 내외로 줄었습니다.

## 배운 점

패턴이 반복되는 작업은 AI 보조 도구로 처리할 수 있지만, 운영 코드에 반영할 수 있는지는 사람이 정한 기준과 실제 실행 결과로 판단해야 했습니다. 이번 작업에서는 CSS 산출물과 빌드를 그 기준으로 사용했습니다.
