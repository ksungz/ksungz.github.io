## 담당 범위

Cursor와 회사에서 제공한 AI 도구를 UI 개발 업무에 활용했습니다. UI 관련 규칙과 예시를 정리하고, PR 설명, 문서 초안, QA 체크리스트 등 반복 산출물을 작성할 때 사용했습니다. 회사 제공 PR Review Agent의 저장소 적용 과정에는 UI 파일 필터와 검토 기준을 정리하는 범위로 참여했습니다.

## 실제로 활용한 작업

- SCSS, HTML 마크업과 접근성 관련 코드 검토
- PR 설명, 커밋 메시지와 작업 계획 초안 작성
- Confluence 문서와 QA 체크리스트 초안 작성
- 반복해서 확인하는 UI 개발 기준과 예시 정리
- 생성한 결과를 실제 코드, 문서와 대조해 직접 확인

## 회사 제공 AI 도구 적용

회사 제공 PR Review Agent 자체를 개발한 것은 아닙니다. 저장소 적용 과정에 참여해 UI 파일을 대상으로 하는 필터와 접근성, BEM, SCSS 검토 기준을 정리하고 실행 결과를 확인했습니다.

반복 규칙은 AI가 먼저 확인하도록 구성하되, 설계 의도와 영향 범위, 예외 케이스는 기존 코드 리뷰에서 사람이 계속 확인했습니다.

정량적인 시간 절감이나 검출률은 측정하지 않았기 때문에 별도 성과로 적지 않았습니다.
